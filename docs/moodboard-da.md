# Direction Artistique — Charte Visuelle (Option A)

## Palette de Couleurs
- **Environnement (Zone 1)** :
  - Sol / Arrière-plan : Béton sombre `#1E1E24`, Métal oxydé `#2B2D42`
  - Éléments interactifs : Jaune néon `#FFD166`, Orange alerte `#F77F00`
- **Boss & Ennemis** :
  - Métal de base : Gris acier `#8D99AE`
  - Mode Surchauffe : Rouge incandescent `#EF233C`
- **UI & Telegraphs** :
  - Zones de Dégâts (Zones d'impact) : Rouge semi-transparent `#D90429` (Alpha 0.4)
  - Shields / Zone Safe : Bleu cyan `#00F5D4`

## Spécifications des Assets
- **Format** : Fichiers SVG ou Sprite Sheets PNG avec contours sombres de 2px.
- **Résolution des Sprites** :
  - Joueur / Ennemis de base : 64x64 px
  - Boss (Série X-88) : 128x128 px
